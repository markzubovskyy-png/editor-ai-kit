# colour-grade

Real code: `scripts/grade.py`. Every grade is a .cube 3D LUT generated by the
script and applied with ffmpeg's `lut3d`, so the options still shows exactly
what the render will look like. Needs Python 3.9+ and ffmpeg on PATH.
numpy is not needed. Pillow (already needed by motion-render) adds labels to
the options still.

## The looks

| # | Look | What it does |
|---|---|---|
| 1 | warm | golden, soft, a little richer |
| 2 | cold | cool blue teal mids and shadows, calmer colour |
| 3 | cinematic | contrast curve, teal shadows, warm highlights, calmer cyans |
| 4 | rec709 | clean and neutral, the safe default |
| | match | nudges the clip toward a reference still the editor sends |

Flat log footage (Sony S-Log3) is detected automatically and converted
first. For other log formats, ask the editor to export with the camera's own
Rec.709 LUT applied, then grade from there.

## The flow over Telegram

1. **Editor sends a clip** and asks for colour options. Telegram bots can
   only download files up to 20 MB. For bigger clips, ask for a short
   export, a link you can download, or a path in a shared folder.
   Use the Telegram plugin's `download_attachment` tool to save the file.
2. **Always ask about a reference look if they didn't give one**: "Got a
   frame from a video whose colour you love? Send it and I'll match it.
   Otherwise here are four options." Don't skip this question.
3. **Make the options still**:
   ```bash
   python3 scripts/grade.py options jobs/<job>/clip.mp4 --out jobs/<job>/graded
   ```
   This writes `<clip>_options.jpg`, a 2x2 grid labelled 1 WARM, 2 COLD,
   3 CINEMATIC, 4 REC709. Send it back and ask them to pick a number. If
   `brand/style.md` has a `Grade look:`, mention which one is the team
   default.
4. **Render the pick**:
   ```bash
   python3 scripts/grade.py render jobs/<job>/clip.mp4 --look cinematic --chat-copy --out jobs/<job>/graded
   ```
   or match a reference still:
   ```bash
   python3 scripts/grade.py render jobs/<job>/clip.mp4 --match jobs/<job>/ref.jpg --chat-copy --out jobs/<job>/graded
   ```
   `--look all` renders all four. `--strength 0.5` softens a look (match
   defaults to 0.75 so it nudges rather than repaints). `--exposure 0.5`
   brightens by half a stop. `--prores` writes ProRes 422 HQ masters
   instead of H.264.
5. **Send back** the `_chat.mp4` (always under 45 MB, so it fits Telegram's
   50 MB limit for bots) and the `_before-after.jpg`. Tell them where the
   full quality file and the `.cube` are on the brain if they want to apply
   the same LUT in Premiere, DaVinci, Final Cut or CapCut.

Each render writes, in `--out`:
`<clip>_<look>.mp4` (full quality), `<clip>_<look>.cube`,
`<clip>_<look>_before-after.jpg`, and with `--chat-copy`
`<clip>_<look>_chat.mp4`.

## Using the team default

If `brand/style.md` has `Grade look: cinematic` (and optionally
`Grade reference: grade-reference.jpg`), `render --style brand/style.md`
with no `--look` uses it. That keeps every editor on the same look. When
the founder changes that line, every editor gets the new default.

## Just the LUT

```bash
python3 scripts/grade.py lut --look warm --lut-out warm.cube
```

## Verify before replying

- Look at the options still yourself before sending it: four tiles, the
  right labels, and visibly different looks.
- The last line the script prints is JSON. Check `input` (slog3 or rec709)
  makes sense for the footage and every file listed exists.
- For a render, look at the before and after still. If the match went too
  far, re-run with a lower `--strength`.
